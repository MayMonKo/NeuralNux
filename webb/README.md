# NeuralNux Official Website – Frontend Source Code

This branch contains the complete frontend implementation of the NeuralNux official website.  

The website is designed with a futuristic cyberpunk aesthetic and built using modern frontend best practices, enhanced animations, and security hardening measures.

---

##  Core Objectives

- Provide a professional public-facing website for NeuralNux
- Showcase team branding and mission
- Deliver high-impact UI with modern visuals
- Maintain lightweight, secure, and fast frontend architecture

---

## Technologies & Programming Languages

### Frontend Languages

| Technology | Purpose |
|-----------|--------|
| HTML5 | Website structure and content |
| CSS3 | Styling, animations, layout |
| JavaScript (ES6) | Interactions, animations, plugins |

---

### Frameworks & Libraries

| Tool | Usage |
|-----|------|
| Bootstrap 5 | Responsive layout system |
| AOS (Animate On Scroll) | Scroll-based animations |
| GLightbox | Image modals |
| Isotope | Layout filtering |
| Swiper.js | Sliders & carousels |
| PureCounter | Animated counters |
